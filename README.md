# Haas Builds 🐻

A Product Hunt for what Haas / Berkeley students are building with AI. Share your project, upvote others, join builds, find collaborators, and stop five people from building the same thing.

- **Live:** https://haas.build
- **Access:** @berkeley.edu Google accounts only (enforced server-side)
- **Stack:** static frontend (this repo) + Supabase (auth, Postgres, RLS) + Cloudflare Pages

No build step. `index.html` + `app.js` + `styles.css`, deployed from `main`.
