# Berkeley Builds 🐻

A Product Hunt for what Haas / Berkeley students are building with AI. Share your project, upvote others, find collaborators, and stop five people from building the same thing.

- **Live:** https://yitzybitzyspider.github.io/berkeley-builds/
- **Access:** @berkeley.edu Google accounts only (enforced server-side)
- **Stack:** static frontend (this repo) + Supabase (auth, Postgres, RLS)

No build step. `index.html` + `app.js` + `styles.css`, deployed straight from `main`.
